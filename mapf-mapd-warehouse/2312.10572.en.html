In short: This paper proposes a 'Bulk Search' algorithm for Anonymous Multi-Agent Path Finding (AMAPF) that explores groups of search states simultaneously, significantly outperforming state-of-the-art solvers in runtime and memory efficiency.

What is this paper about?

Anonymous Multi-Agent Path Finding (AMAPF) involves assigning agents to goals in a graph such that all goals are reached without collisions, minimizing the makespan. While AMAPF can be reduced to a maximum flow problem on an auxiliary graph, the resulting graph's size can become a bottleneck for standard search algorithms.

What is new compared with prior work?

The authors introduce a novel search algorithm that leverages the specific topology of the auxiliary flow network to perform 'bulk expansion' of search states. By implicitly compressing and expanding groups of states as single entities, the method achieves a massive reduction in the number of node expansions, runtime, and memory usage. The proposed solver (flow-BS) outperforms the current state-of-the-art (flow) across all MovingAI benchmark instances, solving them in under 30 seconds.

What is the key technical idea?

The method builds upon the reduction of AMAPF to a maximum flow problem. Instead of using the standard Ford-Fulkerson approach which expands individual states, the proposed 'Bulk Search' identifies 'connected sequences' of states within the network. These sequences are treated as a single bulk during the search process, allowing the algorithm to traverse the search space much more efficiently by reducing the total number of expansions required to find the maximum flow.

How was it validated?

The performance of the proposed 'flow-BS' solver was validated against the state-of-the-art 'flow' solver using the MovingAI MAPF benchmark. The evaluation included 33 maps and 25 random scenarios, testing agent counts from 1 up to 1,000. Success rates were measured under a 30-second time limit, and the growth of node expansions relative to the optimal makespan was analyzed to demonstrate scalability.

What are the limitations and open questions?

The results demonstrate that the proposed method is particularly effective when the optimal makespan cannot be accurately estimated beforehand, as it maintains much lower expansion rates than existing methods. The authors note that while the solver is highly efficient for makespan optimization, extending the technique to support cost-based objectives (like Min-Cost-Maximum-Flow) remains a subject for future work. Additionally, the current work focuses on discrete graphs rather than continuous workspaces.

Detailed section summary

Background

Multi-Agent Path Finding (MAPF) is a critical problem in robotics, automated warehouses, and video games. AMAPF is a specific variant where agents are interchangeable, meaning any agent can satisfy any goal, which simplifies the problem's complexity compared to standard MAPF.

Limitations of prior work

The problem is to find a set of collision-free paths for agents in a graph such that every goal vertex is visited by at least one agent, minimizing the time at which the last agent reaches its goal (makespan). This combines the task of goal assignment with the task of pathfinding.

Technical highlights

The core technical innovation is the concept of 'connected sequences' used for bulk state expansion. This allows the search to bypass the overhead of individual state management by processing multiple related states in a single step.

Experiments

Experiments were conducted on a PC with an Intel Core i7-10700F CPU and 32GB of RAM. The researchers used the MovingAI benchmark, which provides a standardized set of maps and scenarios to test the robustness and speed of MAPF solvers.

Results

The flow-BS solver achieved a 100% success rate on all MovingAI benchmark instances within the 30-second limit. Furthermore, the number of expanded nodes in flow-BS grew much more slowly than the competitor as the optimal makespan increased, proving superior scalability.

Conclusion

The paper concludes that the proposed bulk search approach effectively addresses the scalability issues of reduction-based AMAPF solvers. By exploiting the structure of the auxiliary flow network, the algorithm provides a significant performance leap over existing state-of-the-art methods.

Limitations and open problems

The study does not address the sum-of-costs objective, focusing only on makespan. The scope is limited to agents moving on a discrete graph rather than in a continuous geometric space.

Why it matters to MAPF researchers

Efficiently solving AMAPF is vital for large-scale logistics and autonomous systems where many interchangeable agents must reach various destinations quickly and without collision.

Who should read this paper

Researchers working on multi-agent coordination, combinatorial optimization, and large-scale path planning in discrete environments.
