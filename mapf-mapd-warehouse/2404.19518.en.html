In short: This paper studies multi-goal multi-agent path finding, in which every agent must visit its assigned set of multiple goals without conflicts. It shows that decoupling goal-vertex ordering from single-agent path finding does not always preserve optimality, and proposes MGCBS with a Time-Interval-Space Forest; in the reported evaluation, MGCBS consistently found optimal solutions and achieved a speedup of up to seven times.

What is this paper about?

The MG-MAPF problem places multiple agents on an undirected graph with unit-length edges. Each agent may wait or move to an adjacent vertex at every time step, and must visit all of its pre-assigned goals at least once in any order. Agents may not occupy the same vertex at the same time or move along the same edge at the same time, and after completing all visits an agent remains at one of its goal vertices. The objective is to minimize the sum of the individual path costs, where an agent’s cost is the number of time steps needed to complete its goal visits.

What is new compared with prior work?

The paper first demonstrates that DVS methods, which decouple goal-vertex visiting-order search from single-agent path finding, cannot always guarantee an optimal MG-MAPF solution. It then introduces Multi-Goal Conflict-Based Search, or MGCBS, based on decoupling goal safe-interval visiting-order search from single-agent path finding. A safe interval is used to represent time-dependent availability of a goal under the relevant constraints. The paper also proposes the Time-Interval-Space Forest, which reuses shortest-path information from arbitrary start vertices and start times to goal safe intervals, and presents theoretical arguments for MGCBS optimality and completeness.

What is the key technical idea?

MGCBS is a two-level solver. Its high-level component extends Conflict-Based Search by maintaining a constraint tree, selecting a lowest-cost node, detecting conflicts, and generating child nodes by adding constraints for the conflicting agents. Its low-level component uses an A*-based search to find the best safe-interval visiting order and a corresponding path for one agent under the node’s constraints. For each agent, a TIS Forest consists of several Time-Interval-Space Trees, with one tree associated with a particular goal safe interval. These trees provide the shortest path and length from a start vertex at a start time to the associated safe interval, reducing repeated shortest-path queries.

Detailed section summary

Background

Multi-agent path finding asks for collision-free paths from agent starts to goals and is relevant to applications such as aircraft towing, video games, and traffic management. MG-MAPF extends this setting by assigning multiple goals to each agent. The paper distinguishes MG-MAPF from related multi-goal settings such as multi-agent pickup and delivery, MAPF with precedence constraints, and simultaneous multi-goal sequencing and path finding, because those problems impose different requirements. Earlier MG-MAPF approaches include HCBS and SMT-HCBS; the paper characterizes HCBS as typically faster because of its heuristic search, while leaving room for improvements in both optimality and efficiency.

Limitations of prior work

The input consists of an undirected unit-edge graph, a set of agents, one start vertex for each agent, and multiple assigned goal vertices for each agent. Agents can wait or move at each time step, and they must visit every assigned goal at least once in an arbitrary order. A vertex conflict occurs when two agents occupy one vertex simultaneously; an edge conflict occurs when they move along the same edge at the same time. The objective is the sum of the completion times of all agents. The need to choose visit orders while respecting time-dependent interactions is the central difficulty addressed by the paper.

Technical highlights

A TIS Forest is maintained per agent and contains multiple TIS Trees, each associated with a particular goal safe interval. The structure records shortest paths from time-space states toward a safe interval and can answer queries for different start vertices and start times. The theoretical discussion characterizes the tree construction as a backward version of Dijkstra’s algorithm and explains that states within a TIS state can be expanded together along reverse edges. Because the exact time at which a goal will be reached is unknown beforehand, the structure cannot simply be built using a mechanism analogous to SIPP. Conclusion

The study concludes that separating goal-vertex ordering from single-agent path finding is insufficient for optimal MG-MAPF. MGCBS instead searches over goal safe-interval orders while using CBS-style conflict resolution and an A*-based low-level solver. The TIS Forest makes this approach more efficient by reusing shortest paths to safe intervals from many time-space starting states. Within the reported four-neighbor grid evaluation, the method combines the claimed optimality with substantially better runtime than the DVS-based state-of-the-art method.

Why it matters to MAPF researchers

The work is important because it identifies a fundamental limitation in a natural decomposition for multi-goal planning: a vertex order can fail to be optimal when temporal availability and inter-agent conflicts are considered. By making safe intervals part of the ordering problem, MGCBS connects goal sequencing with time-dependent feasibility while retaining a CBS architecture. The TIS Forest further shows how an exact solver can reuse repeated shortest-path computations rather than abandoning optimality for speed. This makes the approach relevant to researchers studying exact coordination for fleets with multiple assigned tasks.
