What is new compared with prior work?

The main contribution is a general framework for adding pattern-database values over disjoint variable subsets while preserving admissibility. In a statically partitioned heuristic, the variables are divided into fixed groups before search, and one value is retrieved for each group. In a dynamically partitioned heuristic, multiple candidate patterns are precomputed and the partition that maximizes the current sum is selected separately for each search state. The paper applies this idea to three substantially different domains and connects it with stronger distance constructions for sliding-tile puzzles, including pairwise and higher-order patterns. It also shows how matching and vertex-cover formulations can select compatible pair costs or capture additional conflict lower bounds.

What is the key technical idea?

During preprocessing, the method solves relaxed subproblems for selected variable subsets and stores the minimum cost from each abstract state to the goal. Reverse breadth-first search is used for the finite pattern spaces described in the excerpt, although the general idea is not tied to one preprocessing procedure. During search, the current state is mapped to an entry in each relevant database, and the retrieved values are summed. The admissibility argument assigns each operator's cost to the pattern variables it affects; when no operator affects variables in more than one pattern, the sum of attributed pattern costs cannot exceed the cost of the original solution. Static heuristics perform a fixed lookup-and-add operation, whereas dynamic heuristics solve a selection problem at each state to choose compatible patterns with the largest total value. For sliding-tile databases, the blank position can be omitted from the index and the minimum over possible blank positions stored, reducing memory through a compressed abstraction.

Dynamic partitioning can produce a larger heuristic value for a particular state because it chooses the best available disjoint grouping rather than committing to one grouping in advance. Detailed section summary

Background

Classical admissible heuristics can be understood as exact solution costs in relaxed problems. For a sliding-tile puzzle, ignoring the requirement that a destination be empty yields independent tile movement and the Manhattan-distance lower bound. Pattern databases generalize this idea by retaining selected tiles or variables and solving their induced subproblem exactly. Adding several databases is attractive because separate abstractions can capture different interactions, but it is safe only when the cost accounting prevents double counting.

Limitations of prior work

A weak relaxation is inexpensive but may ignore important conflicts among objects, causing a search algorithm to expand many states. A stronger abstraction can retain several objects together, but its database grows and its lookup or construction cost increases. Combining overlapping abstractions can count one operator multiple times and invalidate admissibility. The design problem is therefore to obtain a large lower bound while controlling preprocessing, memory, and per-state selection time.

Technical highlights

For a static additive heuristic, all variables are assigned to disjoint groups once, and the database values of those groups are always added. For a dynamic heuristic, databases for pairs, triples, or other candidate subsets are available, and a compatible collection with maximum current sum is selected for each state. Pairwise tile costs can be represented by a mutual-cost graph and selected through maximum-weight matching. Conflict constraints can also yield vertex-cover lower bounds; for clique partitions, the cover size of each clique supplies an additive component. The soundness condition is domain-dependent: the excerpt specifically relies on the fact that one operator does not affect variables in more than one selected pattern.

Experiments

In the sliding-tile domain, the study compares several static tile partitions with dynamic partitioning using iterative-deepening search. In the peg Towers of Hanoi domain, disks are divided into disjoint groups, and a database records the cost of moving each group's disks to the goal peg while ignoring other disks. In vertex cover, vertices are partitioned into vertex-disjoint cliques and the clique-based lower bounds are added during search. Conclusion

The paper concludes that static and dynamic additive pattern-database heuristics are effective admissible heuristics in sliding-tile puzzles, peg Towers of Hanoi, and vertex cover. It presents them as among the best known admissible heuristics for the studied problems and as effective tools for finding optimal solutions to arbitrary instances, subject to domain-specific conditions. For the standard initial and goal configurations of Towers of Hanoi, specialized breadth-first methods exploiting symmetry may solve larger instances, so that comparison has a narrower scope than arbitrary-instance heuristic search.
