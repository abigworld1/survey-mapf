What is the key technical idea?

The multi-agent problem is formulated using stochastic games, in which each agent has states, available actions, transition dynamics, and rewards. A common weighted automaton specifies the task for every agent, and the weight accumulated along an agent trajectory represents how well that trajectory satisfies the objective. For reach-avoid tasks, the reward structure distinguishes reaching the goal from colliding with an obstacle and is designed so that, among collision-free trajectories, earlier arrival receives greater value. This is motivated by a limitation of integral-style robustness measures: an agent that reaches a goal quickly and then leaves it can receive less cumulative value than an agent that takes a longer route and remains at the goal. Agents are trained centrally under a shared policy, so experiences from multiple agents can be pooled. Evolutionary-game-based updates modify the stochastic action distribution using generated trajectories, with the intention of improving team behavior through shared and increasingly diverse experience.

Detailed section summary

Background

Classical multi-agent path finding commonly uses graph search and combinatorial-optimization heuristics to route agents to assigned goals without collisions. Reinforcement-learning approaches can learn behavior from state-based or user-specified rewards, but short-horizon rewards may encourage undesirable long-term behavior, including reward hacking. Automata-based specifications, temporal logic, robustness measures, and non-Markovian reward models have therefore been explored for tasks whose value depends on history and time. Weighted automata extend this direction by associating transition weights with an accepting task structure.

Limitations of prior work

The problem is to synthesize policies for multiple agents that reach goals safely and efficiently under uncertain transitions. A binary success signal is insufficient when successful trajectories differ in arrival time, path length, or safety-related behavior. A useful specification must capture both whether the task is completed and how well the complete trajectory satisfies the intended temporal objective. The agents may also need to learn without prior knowledge of the goal location.

Technical highlights

A weighted automaton is a finite-state task model with accepting conditions and weights on transitions. The proposed reward construction gives special treatment to goal-reaching transitions and obstacle collisions, and the paper states that faster collision-free goal-reaching trajectories obtain higher automaton rewards. The policy is stochastic, with action probabilities updated from shared experience under centralized training. The action set is up, down, left, right, and stay in a two-dimensional grid. Baselines include a heuristic search planner, Monte Carlo, tabular Q-learning, and PPO; the heuristic uses Manhattan distance, and the other methods use the proposed reward structure. Results

The paper reports that MAPF-EGT reduces path length by nearly 30% in large spaces compared with the evaluated reinforcement-learning methods. It is reported to be at least an order of magnitude faster computationally than deep RL and to have computation time comparable to the Monte Carlo method. Q-learning is described as having training and scalability difficulties for large grids, although its short run time makes its scaling with agent count relatively steady. Conclusion

The paper presents a way to combine trajectory-level weighted-automaton objectives with evolutionary-game-based learning for multi-agent path finding. Within the reported grid-world experiments, MAPF-EGT is claimed to improve path efficiency and computation time while scaling favorably with more agents. These findings suggest that explicit temporal reward structure and shared experience can complement conventional reinforcement learning and heuristic planning.

The current study also assumes homogeneous agents and homogeneous tasks, and future work is intended to address more diverse multi-agent learning and convergence guarantees.
