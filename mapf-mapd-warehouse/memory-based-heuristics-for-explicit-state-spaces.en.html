In short: This paper accelerates searches with arbitrary start and goal states by storing true distances for only selected pairs of states and using them to construct heuristics for any pair. It argues that much of the benefit of an all-pairs shortest-path database can be obtained with less than 1% of its memory, and reports 6–14-fold search-speed improvements over traditional heuristics across several domains.

What is new compared with prior work?

The central contribution is a general framework that stores exact distances between selected pairs of states in the original state space and reuses them as admissible heuristic information for arbitrary state pairs. It presents two table-based approaches: differential heuristics, which use differences in distances to reference states, and canonical heuristics, which assign states to representative canonical states. It also studies ways to improve estimates through the number and placement of reference or canonical states, combinations of lookup values, and the maximum of the new heuristic and an existing heuristic. In contrast to pattern databases, which generally depend on a particular pattern or goal structure, the framework is presented as applicable to arbitrary start and goal states without relying on application-specific map properties.

What is the key technical idea?

The state space is treated as a graph. If exact shortest-path distances for every pair were available, the distance between the current state and the goal would be a perfect heuristic, but computing such a database can require up to cubic preprocessing time and quadratic memory in the number of states. A differential heuristic stores distances from a small set of reference states and estimates the distance between two states using the absolute difference between their distances from the same reference. A canonical heuristic assigns each state to a nearby canonical state and combines the distance between the assigned canonical states with the distances from the original states to their assigned representatives. Multiple reference states, canonical states, and existing heuristics can be combined; the experiments use the maximum of the existing heuristic and the canonical heuristics. Canonical states may be placed randomly, by an advanced placement procedure, or by domain-specific rules, with the intended effect of making canonical neighborhoods more favorable for accurate estimates.

Detailed section summary

Background

Heuristic search has often focused on solving larger problems, but map-like domains can instead demand extremely fast solutions to comparatively small problems. Pattern databases are a major memory-based approach for automatically constructing admissible heuristics, and several enhancements have been proposed in the literature. Their usefulness for arbitrary goals is not a general property, while a complete all-pairs shortest-path database is usually too expensive in both storage and preprocessing. The paper combines the generality of state-pair distances with a sparse-memory representation.

Limitations of prior work

The problem is to reduce search time for optimal paths between arbitrary start and goal states without storing the exact distance between every pair. If the graph has N states, an all-pairs shortest-path database requires memory on the order of N squared and may require preprocessing time on the order of N cubed. Such a database can be infeasible even when the state space itself fits in memory. The desired method must therefore provide strong admissible estimates from a small stored sample of exact distances.

Technical highlights

Differential heuristics use the absolute difference between distances from a state pair to a common reference state. Canonical heuristics map states to canonical representatives and use representative-to-representative distances together with local distances to estimate the original pair. The paper states that these heuristics are admissible, but the proof is omitted from the supplied text. A second lookup can triangulate a state and improve its heuristic estimate, and multiple estimates can be combined through their maximum.

Experiments

The main room-map experiment has 206,720 states on a 512-by-512 map and averages 640 problems. The complete all-pairs heuristic has an average optimal heuristic value of 384.59 and is estimated to require 21 billion heuristic entries. The 8-puzzle has 181,440 states and is evaluated on 31,125 problems with an average optimal path length of 21.84 moves. Besides ordinary differential and canonical settings, it includes a domain-structured canonical set consisting of all states whose blank is in the middle, totaling 20,160 canonical states.

Results

On the room maps, octile distance expands 21,686 nodes on average, while 10 canonical states reduce this to 3,440 and 125 canonical states reduce it to 760. The 125-state configuration achieves a 29-fold reduction in expansions using about one-thousandth of the memory needed by the full all-pairs information; the reported maximum time reduction is 13-fold. The paper’s overall abstract reports 6–14-fold search-speed improvements over traditional heuristics across several domains. In the 8-puzzle, the structured set of 20,160 canonical states with depth 3 averages 69 expanded nodes, reported as 40 times better than the Manhattan-distance baseline. These figures are the results supplied in the excerpt and should not be generalized to unreported domains or conditions.

Conclusion

True distance heuristics turn a sparse collection of exact state-to-state distances into reusable guidance for searches with arbitrary starts and goals. The experiments show that most of the practical benefit of complete all-pairs distance information can be approached with much less memory. The method therefore offers a way to accelerate optimal real-time pathfinding and demonstrates that stored memory can be used more flexibly than a goal-specific heuristic table. Its broader value is the general framework, not merely one domain-specific placement rule.

Limitations and open problems

The main formulation assumes that the full state space fits in memory, although the paper mentions abstraction-based algorithms as a possible route for larger spaces. The best number and placement of canonical states remain open, and the paper itself expects better placement methods. The supplied excerpt omits the numerical robotic-arm results, the exact search procedure for the 8-puzzle, and some detailed comparison conditions. The work makes a clear case for converting offline exact-distance computation into online search speed through sparse tables. Its strongest practical message is that a tiny fraction of the memory of an all-pairs database can produce a large reduction in node expansions.
